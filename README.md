# NBA2k27

This project is a lightweight browser-based mini basketball game inspired by NBA 2K27.

## Run it locally

Open `index.html` in a browser, or serve the folder with a local web server:

```bash
cd /workspaces/NBA2k27
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Controls

- Move: W, A, S, D
- Shoot: Spacebar

The game includes a team-selection screen, a basic 3D court, player motion, AI opponent movement, shooting physics, and a score HUD.
